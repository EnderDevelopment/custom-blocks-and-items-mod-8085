# Custom Blocks and Items Mod

Add custom blocks and items to your Minecraft world with ease.

## Features

- Adds a custom block to the game
- Adds a custom item to the game

## Requirements

- Minecraft 1.20.4
- Fabric Loader 0.14.0 or higher

## Installation

1. Download the mod JAR file from the releases page.
2. Place the JAR file in your Minecraft mods folder.
3. Launch Minecraft with the Fabric profile.

## Usage

Once installed, you can find the custom block and item in your creative inventory.

## Configuration

This mod does not have any configuration files. The custom block and item are added automatically when the mod is loaded.
